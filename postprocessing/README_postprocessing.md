# Postprocessing — Figure Generation and Economic Analysis

This folder contains all scripts, data, and outputs required to reproduce
the figures and economic analysis reported in:

> A. Škegro, T. Wik, B. Bijlenga, A. Bessman, C. Zou,
> *System-Level Assessment of Dynamic Reconfiguration for Lifetime and Cost
> Outcomes in Electric Vehicle Battery Packs*,
> Nature Communications (2026).

All figures can be reproduced directly from the pre-computed simulation data
included in `data/` without rerunning the simulations.

---

## How to reproduce all figures

### Option 1: Run all figures at once

```matlab
cd code
run_all_figures
```

This runs all figure scripts sequentially and saves all outputs to the
`results/` subdirectory.

### Option 2: Run individual figure scripts

Each script must be run from its own subfolder (this sets the path context
that the scripts rely on):

```matlab
cd code/fig2
Fig2_SuppFig2              % Fig. 2 and Supplementary Fig. S2

cd ../fig3
Fig3_SuppTableS4           % Fig. 3 and Supplementary Table S4

cd ../fig4-5
Fig4_5_SuppFig3_SuppFig4   % Figs. 4 & 5 and Supplementary Figs. S3 & S4
SuppFig5                   % Supplementary Fig. S5
```

### Option 3: Reproduce via Docker (Code Ocean)

See `REPRODUCING.md` for instructions on reproducing results using the
Code Ocean Docker environment.

## Data description

### Raw simulation outputs (`data/raw/`)

The 240 raw `.mat` files are named according to the parameter combination:

```
out_CHEM_<c>_TC_<tc>_Ns_<n>_T_<t>_Tsig_<ts>_Trest_<tr>_1000.mat
```

| Tag | Parameter | Values |
|---|---|---|
| `CHEM` | Chemistry | 1 (LFP), 2 (NMC) |
| `TC` | BOL variability test case | 1 (tight), 2 (loose) |
| `Ns` | Number of series-connected cells | 4, 16/14, 20, 50, 100, 200 |
| `T` | Mean cell temperature (°C) | 25, 35, 45 |
| `Tsig` | Temperature std. deviation ×100 | 0, 42, 83 |
| `Trest` | Rest fraction ×100 | 20, 95 |

These files are the direct outputs of `simulation/files/RGM_MATLAB_Main_f.m`
and are read-only inputs for the postprocessing scripts.

### Aggregated data files

`results_EFC_2025_06.mat` and `results_summary_2026_06.mat` contain
pre-aggregated lifetime extension statistics across all scenarios,
generated by `batchProcessData.m`. These are used directly by the
figure scripts and do not need to be regenerated unless the raw data
changes.

## Output location

All generated figures and tables are saved automatically to:

```
results/fig2/     # Outputs from Fig2_SuppFig2.m
results/fig3/     # Outputs from Fig3_SuppTableS4.m
results/fig4-5/   # Outputs from Fig4_5_SuppFig3_SuppFig4.m
                  # and SuppFig5.m
```

These folders are created during execution if they do not already exist.
